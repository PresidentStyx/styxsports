Get the TV app

Same games as this site, but made for a TV remote. Most people use a Fire Stick. Pick what you have:

Fire Stick, Fire TV, Google TV, Android TV

This works on Fire Sticks, Fire TVs, Chromecast with Google TV, Onn boxes, Nvidia Shield, and most Android TVs (Sony, TCL, Hisense). The app is not in the store. You add it with a free helper app called Downloader.

  1. Get Downloader.

    On your TV, open the store. Search for Downloader (orange icon, made by AFTVnews). Install it. Open it.

  2. Let Downloader install apps. You only do this once.

    Fire Stick / Fire TV: go to Settings → My Fire TV → Developer Options → Install unknown apps and turn Downloader on.

    If you do not see Developer Options: go to Settings → My Fire TV → About and click your Fire Stick name 7 times. Then go back and it will be there.

    Google TV: Settings → Apps → Security & restrictions → Unknown sources → turn Downloader on.

    Android TV: Settings → Device Preferences → Security & restrictions → Unknown sources → turn Downloader on.

  3. Open Downloader and type this code. Then press Go.

    Downloader code 4602383

    If it asks to use files or storage, say yes.

    Code not working? Type this instead: sports.styxam.com/apk

  4. Press Install. Then press Open.

    If it asks to delete the file after, say yes. You are done. Styx Sports is now in your apps list.

    On a Fire Stick you can move it to the front row: hold the home button on the app, or use Settings → Applications → Manage Installed Applications.

Later updates are easy. When a new version is ready, the app will ask you to install it. The first time, your TV may ask you to allow Styx Sports to install apps. After that, just press Install. You do not need Downloader again.

Roku

Roku does not let you add this from the channel store, so you load it yourself. All you need is your phone on the same Wi-Fi as the Roku. It takes about 5 minutes, and you only do it once.

  1. Turn on developer mode on the Roku. Pick up the Roku remote and press these buttons, one after another, fairly quickly:

    Home Home Home ▲ ▲ ▶ ◀ ▶ ◀ ▶

    (Home three times, Up twice, then Right, Left, Right, Left, Right.) A grey Developer Settings screen appears.

    Write down the address at the top of that screen. It looks like http://192.168.1.50 — yours will have different numbers. You will type it into your phone in step 3.

    Then choose Enable installer and restart. Scroll down and pick I Agree. It asks you to make up a password: type a short one and write it down. The Roku restarts.

    Nothing happened when you pressed the buttons? Do it again a little faster, starting on the Roku home screen.

  2. On your phone, download the channel file. Tap this button. It saves a small file called StyxSports.zip to your phone's downloads. Do not open or unzip it.

    Download StyxSports.zip

    Or type sports.styxam.com/roku into your phone's browser.

  3. On your phone, open the Roku's page. Make sure the phone is on the same Wi-Fi as the Roku. In the phone's browser, type the address you wrote down in step 1 (for example http://192.168.1.50) and go.

    It asks for a username and password. Username is rokudev. Password is the one you made up in step 1.

    If the page won't open: check the phone is on the same Wi-Fi (not mobile data), and that you typed http://, not https://.

  4. Upload the file. On the page that opens, tap Upload (or Choose File). Pick StyxSports.zip from your downloads (iPhone: Browse → Downloads; Android: Files → Downloads). Then tap Install.

    After a few seconds it says Install Success and the Roku switches to Styx Sports by itself.

  5. Next time, Styx Sports is at the end of your Roku home screen. Press OK on it.

Good to know. A Roku can only hold one of these home-made channels at a time. To update Styx Sports later, do steps 2 to 4 again with the new file — same address, same password. If a Roku system update turns developer mode off, do step 1 again. Live TV shows the channels Roku's player can play (HLS).

Phone, tablet or computer

Nothing to install. Open sports.styxam.com in a browser. To put a shortcut on your home screen:

  • Android (Chrome): menu ⋮ → Add to Home screen (or Install app).
  • iPhone / iPad (Safari): Share → Add to Home Screen.
  • Windows / Mac (Chrome or Edge): the install icon in the address bar, or ⋮ → Cast, save and share → Install page as app.

It then opens full screen. On a keyboard: arrows move, Enter plays, Esc closes, R refreshes.
